# VibeFin AI

Интерактивный концепт AI-финансиста для собственника бизнеса.

Сайт показывает, как искусственный интеллект превращает управленческие данные в утреннюю финансовую сводку, предупреждение о рисках и сценарное решение.

## Возможности

- интерактивная сводка по деньгам, прибыли и рискам;
- демонстрация проверки данных;
- сценарная модель с пересчётом ключевых показателей;
- адаптивный интерфейс для телефона и компьютера.
